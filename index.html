CrowdstrikeNovember 3, 2026

CrowdStrike Agrees to Acquire Fiddler AI and Dreadnode for Agent Observability and AI Security Testing

On November 3, 2026, CrowdStrike announced definitive agreements to acquire Fiddler AI and Dreadnode, reported together at roughly $495 million, with close expected in Q4 FY27. Fiddler will become Falcon Observe, adding pre-deployment evaluation, production traces, and explainability for agents, including OpenTelemetry, LangGraph, Amazon Bedrock, AWS Strands, and Google ADK. Dreadnode adds automated pre-deployment AI security testing for jailbreaks and prompt injection, mapped to OWASP, MITRE ATLAS, and NIST AI RMF, and feeds Falcon Guardian and SafeMind. Confirmed on CrowdStrike's newsroom and BusinessWire.

Source

F5 Relevance

Falcon Observe's OpenTelemetry traces and agent tool-call paths are a new control point in front of model and tool APIs. F5 can pair NGINX / BIG-IP API gateway inspection, identity-aware access, and Distributed Cloud WAF with Falcon's pre-deploy and runtime checks so agent traffic is authenticated, rate-limited, and logged before it reaches models or downstream services.

DellNovember 2, 2026

CrowdStrike, Dell, and NVIDIA Launch Integrated Security for the Dell AI Factory

On November 2, 2026, CrowdStrike, Dell Technologies, and NVIDIA announced an integrated security package for the Dell AI Factory with NVIDIA, available through Dell's AI Ecosystem Program and aligned to NVIDIA's AI Factory reference architecture. Falcon Guardian covers agent runtime protection, with planned ties to NVIDIA OpenShell, Sentry, and BlueField-4 DPUs; Falcon Cloud Security covers containers and Kubernetes from code to runtime; Falcon Next-Gen SIEM unifies detection. Dell MDR will monitor the stack 24x7. Announced at Fal.Con Europe 2026.

Source

F5 Relevance

A validated Dell AI Factory stack that already assumes OpenShell, BlueField DPUs, and Kubernetes is a joint-solution opening for F5: BIG-IP and NGINX Ingress in front of the factory, TLS offload and WAF on agent and inference APIs, and Distributed Cloud for consistent policy from deskside nodes to the data center.

NetAppNovember 2, 2026

NetApp Completes Acquisition of PEAK:AIO for Zettabyte-Scale AI Storage

On November 2, 2026, NetApp completed its acquisition of PEAK:AIO, folding the UK firm's metadata services and high-performance parallel file system into NetApp Novus on ONTAP. The combination is aimed at AI clouds and GPU-as-a-service providers that need high concurrency and massive namespaces without copying data off ONTAP's security and resilience features.

Source

F5 Relevance

Zettabyte parallel namespaces feeding GPU clusters increase east-west and S3/NFS traffic that F5 already secures with storage partners. F5 can position BIG-IP and Distributed Cloud in front of Novus and ONTAP endpoints for secure multi-tenant access, TLS, and traffic steering between on-prem namespaces and neocloud GPUs.

NutanixNovember 2, 2026

Nutanix Agent Gateway Goes Generally Available with Enterprise AI 2.7

On November 2–3, 2026, Nutanix said the Agent Gateway is generally available with Nutanix Enterprise AI 2.7. It sits between agents and both hosted frontier models and private models, exposing one API, token quotas, per-team cost attribution, and tool-level controls through Model Context Protocol servers with audit trails.

Source

F5 Relevance

Agent Gateway is an AI control plane that still needs a hardened ingress for MCP and model APIs. F5's API gateway, OAuth/OIDC, and WAF can enforce identity and inspect prompts at the network edge, complementing Nutanix token quotas for hybrid and neocloud NKP deployments.

NvidiaNovember 3, 2026

NVIDIA Finalizes About $1 Billion Stake in Naver to Build AI Factories

On November 3, 2026, Korean outlets including The Asia Business Daily and Aju Press reported that NVIDIA finalized a 1.3412 trillion won investment in Naver, buying 6,558,435 new shares for a 4.13% stake, with payment expected November 6. The dollar amount remains $1 billion. The stake supports a joint AI-factory program in which Naver leads data-center build and operations and NVIDIA supplies GPUs.

Source

F5 Relevance

A confirmed NVIDIA equity stake tied to multi-hundred-megawatt AI factories is an infrastructure design point. F5 can engage on secure delivery into those factories: inference API gateways, DDoS and WAF on tenant endpoints, and multi-site Distributed Cloud between Sejong capacity and global GPU consumers.
