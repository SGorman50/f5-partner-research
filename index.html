CrowdStrike Open Gateway Ecosystem Makes Falcon AI's Control Plane

CrowdStrike expanded Falcon AI Detection and Response (AIDR) across AI gateway partners including Databricks, Google Cloud, Kong, LiteLLM, and Microsoft Azure on June 16, 2026. Equinix Jun 16, 2026

Equinix Launches AI-Ready Data Center HK6 with Direct Hong Kong-Shenzhen Connectivity

Equinix opened HK6, its sixth IBX data center in Hong Kong, with a $124M investment on June 16, 2026. HK6 features liquid-cooling and high-density power for AI workloads with 1,000 initial cabinets (expandable to 3,550) and integrates with Equinix Fabric and the AI Discovery Hub (HPE and NVIDIA). The facility enables cross-border connectivity to Hong Kong-Shenzhen Innovation and Technology Park.

F5 Relevance
HK6 combined with Equinix Fabric is a high-density interconnection point for AI workloads in Asia-Pacific. F5 Distributed Cloud's global PoPs and ability to secure cross-border application traffic make it directly relevant for enterprise customers deploying AI applications across HK6 and the Greater Bay Area.

NetApp Jun 16, 2026

AWS Transform Now Supports Amazon FSx for NetApp ONTAP for Block Storage Migration

AWS announced public preview support in AWS Transform for migrating block storage workloads directly to Amazon FSx for NetApp ONTAP on June 16, 2026. This enables seamless movement of on-premises NetApp environments to cloud without intermediate storage, integrating storage migration with compute and network migration waves in a single unified workflow.

F5 Relevance
As enterprises migrate NetApp ONTAP workloads to AWS FSx, application traffic serving those storage environments also migrates to cloud-native architectures — creating opportunities for F5 Distributed Cloud and NGINX to provide application delivery, API security, and traffic management for the newly cloud-resident ONTAP-backed applications.
Nutanix Jun 15, 2026

Nutanix Announces MCP Server Technology Preview to Bridge AI Agents with On-Premises Infrastructure

Nutanix announced a technology preview of the MCP (Model Context Protocol) Server for Nutanix Cloud Platform on June 15, 2026, enabling AI assistants and LLMs to securely bridge with on-premises Nutanix infrastructure using the open MCP standard. The server has a small footprint (under 10MB) with flexible deployment options including desktop IDE integrations, available at developers.nutanix.com.

F5 Relevance
Nutanix's MCP Server creates new API-accessible control surfaces that require authentication, authorization, and traffic management. F5's API gateway, OAuth/OIDC, and zero-trust capabilities can serve as the security layer protecting MCP-based AI agent access to Nutanix infrastructure, especially in sensitive enterprise and government deployments.
