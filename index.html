Cloud or On-Premises? New Report Shows Why AI Workload Placement Matters

Cisco published an Omdia-backed AI infrastructure report (1,200+ IT leaders) showing 94% of organizations regret their initial AI infrastructure strategy and 96% already run hybrid mixes of cloud, on-prem, and edge. Respondents cite cost surprises, security, data sovereignty, and network bottlenecks (67% expect network capacity to become a limiter) as the reasons they are rebalancing workloads — including moving some AI training and inference back on-premises. Cisco positions unified data-center networking (Nexus One) and observability as the way to treat workload placement as an ongoing operating decision rather than a one-time cloud choice.

Read source

F5 Relevance

This is a direct opening for F5 on AI traffic management, hybrid ADC/WAF, and observability: as customers re-home inference and training across cloud, on-prem, and edge, they need consistent application delivery, API security, and TLS/identity controls that follow the workload. F5 can pair with Cisco/Omdia findings to sell placement-aware BIG-IP, NGINX, and Distributed Cloud designs that keep AI data paths secure when traffic moves back on-prem.

Epic Unveils AI-Driven Ergo Visit at 2026 Users Group Meeting

At its 2026 Users Group Meeting, Epic launched Ergo Visit, an AI-assisted care-planning capability that combines Art (ambient charting), Emmie (patient-facing AI), and Cosmos (320 million deidentified records) to prepare visit agendas and recommend treatments. Clinicians can query Art in real time during encounters for Care Everywhere and Cosmos insights; Best Care Choices for My Patient compares lookalike-patient diagnoses and outcomes. The feature is live at Ochsner Health and with five physicians in Epic’s Garden Plot collaborative.

Read source

F5 Relevance

Ergo Visit adds more AI-to-EHR and FHIR/API traffic inside already regulated health systems. F5 can help Epic customers front those APIs with identity-aware access, WAF/API security, and high-availability delivery so ambient AI and Cosmos queries stay protected and performant across Care Everywhere connections.

HPE Pushes Agentic IT Operations Across GreenLake Intelligence and Morpheus

A August 19 analysis of HPE’s agentic-ops push details how GreenLake Intelligence and HPE Morpheus now span agent observability, orchestration, and governed automation across hybrid IT. OpsRamp Operations Copilot monitors AI agents and LLM token/cost telemetry, while Morpheus Orchestration Copilot provisions multi-step infrastructure workflows under security guardrails; Morpheus–Juniper Apstra integration adds closed-loop, intent-based network automation. HPE CTO Fidelma Russo framed the goal as governing AI infrastructure without fragmentation or unpredictable cost as agents move from recommenders to operators.

Read source

F5 Relevance

Agentic ops that change network and workload state need a policy and traffic-control layer F5 already owns. Partnership or reference-architecture work around GreenLake/Morpheus — API gateway, identity for agents, and WAF/DoS in front of orchestration copilots — would let F5 secure the north-south path those agents use when they provision or remediate production infrastructure.

Nutanix and ChronoScale Announce Strategic Partnership to Accelerate Enterprise AI Adoption

On August 18, Nutanix and ChronoScale (an Applied Digital cloud spinout and NVIDIA Cloud Partner) announced a strategic partnership to integrate ChronoScale GPU-as-a-Service, prepaid Token Factory inference, and a locally deployed ChronoScale Foundry for agentic workflows with Nutanix Cloud Platform. Foundry can be deployed from the Nutanix Kubernetes Platform Catalog; management is intended to sit on Nutanix Agent Gateway and Private Inferencing as a single control plane across on-prem and ChronoScale capacity. Both firms tied the stack to NVIDIA AI economics and joint GTM for Global 2000 customers seeking sovereign, hybrid AI.

F5 Relevance

This is a high-priority NVIDIA-ecosystem play: GPU burst, Kubernetes Foundry, and agent gateways create new inference and API fronts that need load balancing, mTLS/identity, and AI-runtime guardrails. F5 should engage Nutanix/ChronoScale on securing Agent Gateway, NKP ingress, and GPU-as-a-service north-south traffic — the same Secure AI / inference-delivery motion F5 already runs with NVIDIA partners.
