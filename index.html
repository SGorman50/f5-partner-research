NVIDIA Discusses a $2,000-per-GPU Annual Software Fee for AI Agents

Tom's Hardware reported on October 25 that Jensen Huang, speaking at GTC Berlin, discussed a possible $2,000-per-GPU-per-year software license for NVIDIA software that runs AI agents inside AI factories. NVIDIA already charges $4,500 per GPU per year for AI Enterprise. The outlet says scope, timing, and whether the figure replaces or sits beside AI Enterprise are not confirmed. The discussion follows the October 21 OpenShell Reference Architecture, which was already reported.

Source

F5 RELEVANCE

A per-GPU agent software license changes the economics of AI-factory inference. Customers will still need a secure ingress, API gateway, and policy enforcement point in front of agent runtimes. F5 Distributed Cloud and NGINX can sit on that north-south path regardless of how NVIDIA prices OpenShell and AI Enterprise.
