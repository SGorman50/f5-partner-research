Cisco DefenseClaw and NVIDIA OpenShell Guard Enterprise Coding Agents

Cisco published on October 21 how DefenseClaw sits inside NVIDIA OpenShell sandboxes to policy-check tool calls, web access, and session changes for coding agents. OpenShell keeps a zero-trust runtime; DefenseClaw adds guardrails and an audit trail that can export to Splunk or OpenTelemetry.

Source

F5 Relevance

Coding-agent traffic still needs an ingress and API security layer outside the sandbox. F5 can front OpenShell and DefenseClaw endpoints with BIG-IP or NGINX, enforcing mTLS, rate limits, and WAF policy, and consume the same OpenTelemetry audit stream Cisco already exports.

CrowdStrike and NVIDIA Expand AI Agent Security from Software to Silicon

CrowdStrike said on October 21 that Falcon Guardian AIDR now extends across NVIDIA OpenShell and is planned to integrate with NVIDIA Sentry on BlueField-4 DPUs. The pairing ties agent prompts and runtime activity to Falcon context and adds out-of-band, in-silicon enforcement.

Source

F5 Relevance

Falcon Guardian and OpenShell still sit behind enterprise ingress. F5 Distributed Cloud and NGINX can enforce identity-aware access and API policy on the agent endpoints CrowdStrike is instrumenting.
