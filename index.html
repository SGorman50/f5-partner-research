Cisco · October 21, 2026

Cisco Introduces an AI Inference Routing Blueprint with NVIDIA

At NVIDIA GTC Berlin on October 21, Cisco introduced a blueprint for AI Inference Routing, developed with NVIDIA, so service providers can place, route, secure, and assure inference across a distributed footprint. The design treats latency, throughput, cost, and jurisdictional constraints as routing inputs so idle regional capacity can serve demand elsewhere instead of being pre-provisioned site by site. A companion GTC post describes how Cisco AI Defense and NVIDIA Sentry on BlueField-4 DPUs can layer application and infrastructure controls for agent traffic inside the Secure AI Factory.

Source

F5 Relevance

Inference routing that weighs latency, cost, and data-residency is the same class of problem F5 solves with BIG-IP, NGINX, and Distributed Cloud for application and API traffic. F5 can pair Cisco's WAN blueprint with an application-layer inference gateway that terminates TLS, enforces API policy, and steers model traffic without exposing agent credentials on the network path.

CrowdStrike · October 19, 2026

CrowdStrike and the FBI Disrupt North Korean Laptop-Farm Hiring Schemes

The Elec reported on October 20 that CrowdStrike announced on October 19 it had identified organizations and U.S. locations tied to North Korean laptop farms and worked with the FBI to disrupt them. Between April and June, CrowdStrike's Counter Adversary Operations team traced fake identities, technical indicators, and U.S.-based facilitators used by FAMOUS CHOLLIMA to place operators in jobs at aerospace, energy, finance, healthcare, and defense companies. CrowdStrike said the disruption will only temporarily slow the activity as the group changes delivery addresses and methods.

Source

F5 Relevance

Insider-threat and identity-fraud campaigns that land on corporate endpoints still traverse application and remote-access paths F5 already sits on. F5 can pair Falcon identity signals with BIG-IP APM and Distributed Cloud access policy so a compromised contractor identity cannot reach internal APIs even after the endpoint looks clean.

HPE GreenLake · October 20, 2026

HPE Spaceborne Computer-4 Will Run AI and HPC Benchmarks on the Moon

On October 20, HPE announced Spaceborne Computer-4, a fanless compute module planned to run the first high-performance computing benchmarks and AI workloads on the lunar surface. NASA, Deloitte, and HPE will deploy the system on Astrolab's FLIP rover under NASA's CLPS program, testing LLM retrieval-augmented generation, vision inference, and LiDAR processing at the lunar edge. The stack includes a CPU and GPU, KIOXIA solid-state storage, and HPE Private Cloud and CloudOps software.

Source

F5 Relevance

A disconnected lunar edge that must run RAG and vision inference without a reliable Earth link is an extreme case of the edge application-delivery problem F5 already sells. F5 Distributed Cloud and NGINX can be the policy and API layer for Private Cloud AI workloads that must keep working when the backhaul is intermittent, including on sovereign or air-gapped GreenLake sites.

Nutanix · October 21, 2026

Nutanix and Netris Build a Multitenant Stack for Neoclouds and NVIDIA Cloud Partners

On October 21 at NVIDIA GTC Berlin, Nutanix and Netris announced a jointly engineered multitenant infrastructure stack that combines Nutanix Cloud Platform with Netris Network Automation, Abstraction, and Multitenancy. The design is meant to let neoclouds launch NVIDIA GPU-accelerated IaaS faster while enforcing hard isolation on networking hardware between tenants, from compute and DPUs through physical switches. Enterprises would consume bare-metal and virtualized GPU capacity through a cloud-like self-service experience.

Source

F5 Relevance

Hard tenant isolation that stops at the switch still leaves the north-south API and inference path shared. F5 BIG-IP and Distributed Cloud can be the per-tenant application delivery and WAF layer in front of Nutanix GPU services so each neocloud customer gets its own TLS, rate limits, and API policy without trusting soft isolation alone.

Nvidia · October 21, 2026

NVIDIA Launches the OpenShell Reference Architecture for Safe AI Agents

On October 21, NVIDIA launched the OpenShell Reference Architecture, a full-stack design to build, contain, observe, and enforce safe agents from AI factories to the edge. It pairs Vera Rubin for model inference, Vera CPUs for agent harnesses, and BlueField-4 DPUs running NVIDIA Sentry for in-silicon enforcement, and it runs on Canonical, Red Hat, and Microsoft. Cisco, CrowdStrike, Dell Technologies, HPE, Palo Alto Networks, and others are working with the architecture. The same day, Google Cloud said A5X instances based on Vera Rubin NVL72 will reach general availability next month, with a planned scale of up to 960,000 Rubin GPUs.

Source

F5 Relevance

OpenShell moves agent policy into the runtime and the DPU, which is adjacent to where F5 terminates and inspects application traffic. F5 can be the external enforcement point for OpenShell agents — API gateway, mTLS, and WAF — so tool calls that leave the sandbox still pass through F5 policy before they reach enterprise APIs or S3.

Red Hat · October 21, 2026

Red Hat AI Factory with NVIDIA Adds Agentic Security on OpenShell

Business Wire, carried by FinancialContent on October 21, reported that Red Hat and NVIDIA expanded Red Hat AI Factory with NVIDIA to accelerate agent safety across the open hybrid cloud. The update centers on an OpenShell-based agent sandbox with standardized guardrails, operational visibility, and runtime safety, plus model-as-a-service access control, an AI gateway, and GPU orchestration for open-weight inference. It also includes day-0 enablement for NVIDIA Vera Rubin so the platform can host the OpenShell Reference Architecture.

Source

F5 Relevance

Red Hat's AI gateway and OpenShell sandbox still need a production ingress and API security layer in front of OpenShift. F5 NGINX Ingress and BIG-IP can enforce mTLS, rate limits, and WAF policy on the agent and model APIs that Red Hat AI Factory exposes, including when those APIs span OpenShift and Vera Rubin nodes.
