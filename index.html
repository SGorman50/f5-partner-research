Red Hat June 26, 2026

What’s New in OpenShift GitOps 1.21

Red Hat released OpenShift GitOps 1.21 on June 26, 2026, featuring Technical Preview support for the Argo CD Agent Control Plane architecture, enabling incremental migration from centralized to agent-based GitOps management across distributed Kubernetes clusters. The release upgrades Argo CD from 3.3 to 3.4 and promotes the OpenShift Console Plugin for Argo CD resource visibility to Technical Preview. Secret management for webhooks and the GitOps Operator has been simplified with standalone creation and automatic copying into shared secrets.

F5 Relevance

OpenShift GitOps 1.21’s agent-based Argo CD architecture expands declarative Kubernetes deployment patterns across distributed clusters — precisely where F5’s NGINX Ingress Controller and BIG-IP Container Ingress Services (CIS) operate. F5 can position its ingress and API gateway components as GitOps-native, enabling joint reference architectures with Red Hat where F5 networking is declared and managed via Argo CD alongside application workloads.
