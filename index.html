Arista CEO Raises FY2026 Growth Guidance to 28% at BofA Global Technology Conference

Intel June 3, 2026

Intel Launches Ethernet E835 Controllers (200 GbE) and Xeon 6+ Processors with Agentic AI Focus

Intel announced on June 3, 2026 the Ethernet E835 Controllers and Network Adapters (800 Series), delivering up to 200 GbE for high-density AI, cloud, edge, and Telco deployments. MinIO June 1, 2026

MinIO Adds NVIDIA Vera BlueField-4 STX Support to Secure AI Data Pipelines with Silicon-Level Protection

MinIO announced on June 1, 2026 support for NVIDIA Vera BlueField-4 STX and DOCA Vault, integrating silicon-level security into its AIStor S3-compatible object storage stack. Nvidia June 4, 2026

NVIDIA and TSMC Begin Shipping Spectrum-X Co-Packaged Optics Switches for AI Data Centers (400 Tbps)

NVIDIA, in collaboration with TSMC, announced and began shipping next-generation Spectrum-X co-packaged optics (CPO) switches on June 4, 2026, delivering up to 400 Tbps throughput while reducing power consumption and transmission distance. The Vera Rubin platform simultaneously ramped into full production, featuring CPO-based 200 Gb/s SerDes Ethernet photonics, BlueField-4 DPUs with Confidential Computing, and a unified agentic AI stack with Microsoft.

⚡ F5 Relevance

Red Hat June 1, 2026

Red Hat Discloses Supply Chain Compromise of @redhat-cloud-services npm Packages (RHSB-2026-006)

On June 1, 2026, Red Hat disclosed a supply chain security incident (RHSB-2026-006) affecting npm packages under the @redhat-cloud-services namespace, linked to a compromised GitHub account. The incident affected frontend JavaScript libraries in the Hybrid Cloud Console; Red Hat confirmed no production releases were published during the compromise window. Affected package versions were removed from npm, and all builds are being validated.

⚡ F5 Relevance

Supply chain security incidents affecting cloud-service packages are directly relevant to F5's application and API security portfolio — F5's WAF, API gateway, and threat detection solutions can be positioned as a defense-in-depth layer for organizations consuming Red Hat cloud services.
