CrowdStrikeOctober 5, 2026

Falcon Cloud Security Adds Third-Party App Insights and AI Remediation Plans

On October 5, 2026, CrowdStrike said Falcon Cloud Security now maps the third-party and SaaS services cloud-native apps depend on, so teams can see which applications are exposed if a vendor is compromised. AI-enhanced remediation turns that risk context into prioritized fix plans with evidence, urgency, and estimated effort. The update expands application-security posture management beyond the customer’s own cloud footprint.

CrowdStrike blog

F5 Relevance

Third-party API dependency maps are a natural insertion point for F5 API security and WAF policy in front of those SaaS and internal APIs. Joint stories with CrowdStrike could pair Falcon’s cloud risk context with F5 Distributed Cloud / NGINX controls on the traffic path those dependencies use.

DellOctober 4, 2026

Health-ISAC Flags Max-Severity Unauthenticated Flaws in Dell Container Storage Modules

A Health-ISAC TLP:WHITE bulletin dated October 4, 2026 warned that Dell Container Storage Modules CVE-2026-63688 and CVE-2026-63692 (both CVSS 10) let unauthenticated attackers pull storage-backend admin credentials and take over the authorization proxy. Dell patched CSM in 1.18.0 on October 1; the October 4 bulletin is the new public health-sector alert covering PowerStore, PowerScale, PowerFlex, PowerMax, and Unity XT attached to Kubernetes. AHA guidance is to upgrade immediately, rotate backend admin credentials, and segment the authorization proxies.

AHA / Health-ISAC

F5 Relevance

CSM is the path between Dell storage and Kubernetes, so unauthenticated admin access is both a data-plane and cluster-control risk. F5 can position BIG-IP or Distributed Cloud as the authenticated, segmented front door for storage and CSI APIs, and use the bulletin as a joint hardening story with Dell storage teams.

EpicOctober 4, 2026

Epic Still Pausing Product Work to Patch AI-Found MyChart Access Bugs

Northwest Arkansas Democrat-Gazette (October 4) and Becker’s (October 5) report Epic is using Anthropic Claude Mythos, via Project Glasswing, to find ways patient records could be viewed without an audit trail, and has paused much product development for about six weeks to patch. CEO Judy Faulkner says the product roadmap is otherwise unchanged. Epic also warned patients that AI-generated phishing is impersonating MyChart, including a “MyChart Medicare Kit” lure; Epic says the platform itself is not compromised.

Northwest Arkansas Democrat-Gazette

F5 Relevance

MyChart is a large internet-facing app surface. F5 WAF, bot defense, and API security can sit in front of patient portals while Epic patches auth and audit gaps, and phishing-resistant access (F5 APM / identity-aware proxy) is a concrete offer for health systems during the six-week freeze.

HPE GreenLakeOctober 5, 2026

Computer Weekly Details Vultr’s $1.2B HPE AMD Helios Rack Order

Computer Weekly reported October 5 that Vultr is deploying HPE’s AMD Helios AI racks at several US data centers, HPE’s first Helios order, worth about $1.2 billion. Each rack pairs 72 AMD Instinct MI455X GPUs with six HPE Juniper QFX5252 scale-up Ethernet switch trays, liquid cooling, and open Ethernet rather than a proprietary GPU fabric. The piece ties the order to HPE lifting its fiscal 2027 networking growth outlook.

Computer Weekly

F5 Relevance

Scale-up Ethernet between GPUs is a networking design F5 can attach to for north-south AI ingress, WAF, and API security on the same racks. A joint HPE GreenLake story can contrast Juniper scale-up fabric with F5 securing the inference and agent APIs those racks expose.

NetAppOctober 5, 2026

Diskover Catalogs Unstructured Data Across ONTAP and StorageGRID

On October 5, 2026, Diskover Data said it will extend its governed metadata catalog to NetApp ONTAP and StorageGRID for media, semiconductor EDA, and other file-heavy workloads. Scanners index ownership, permissions, age, cost, and project context in place. Customers can buy Diskover through NetApp starting November 2026. The same day SiliconANGLE reported NetApp and Oracle are co-engineering a native managed ONTAP service on OCI for mission-critical apps.

PR Newswire

F5 Relevance

StorageGRID plus a metadata catalog is an S3 data-path F5 already load-balances. Discovery of sensitive files is a hook for F5 S3/API security policy on the same buckets, and the OCI ONTAP service is another hybrid data-mobility path where BIG-IP or Distributed Cloud can front multiprotocol access.
