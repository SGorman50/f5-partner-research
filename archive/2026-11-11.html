DEWA and Dell Technologies Sign a Smart-Grid Cyber Resilience MoU

Dubai Electricity and Water Authority and Dell Technologies signed a memorandum of understanding on November 8, 2026 to explore cyber resilience, business continuity, and modernization of Dubai’s smart grid and substations. Fast Company Middle East reports the pact covers edge computing, data management, secure remote monitoring, and pilot reference designs for grid reliability and recovery. The work is framed as building a secure digital foundation for AI-driven operations on existing utility platforms.

HPE GreenLakeNovember 10, 2026

RACS Moves Remaining Workloads to HPE Private Cloud on GreenLake

Hewlett Packard Enterprise said the Royal Australasian College of Surgeons is moving remaining on-premises workloads to HPE Private Cloud PC3000, managed through GreenLake. The turnkey stack uses HPE Alletra storage, ProLiant DL360 Gen12 servers, and HPE networking switches. HPE says the shift is expected to cut virtualization licensing costs by up to 70 percent and save about AU$2.1 million over five years, with the migration completed without interrupting member services.

Source

F5 Relevance

GreenLake private-cloud migrations still need application delivery, TLS offload, and API protection in front of exam, training, and compliance systems. F5 can attach NGINX or Distributed Cloud as the ingress and WAF layer on PC3000 estates that HPE is selling as a VMware alternative.

IntelNovember 10, 2026

DataKrypto and Intel Target Encrypted AI Execution on Xeon 6 and Intel GPUs

DataKrypto announced a collaboration with Intel to integrate FHEnom for AI with infrastructure based on Intel Xeon 6 processors and Intel GPU D-series, formerly Crescent Island. The design keeps model weights encrypted from storage through GPU execution so the accelerator does not hold keys, combining Intel TDX confidential computing with fully homomorphic-style encrypted inference. Customers can choose thick-client encryption on premises or thin-client encryption inside an attested TDX environment before GPU execution.

Source

F5 Relevance

Encrypted inference still crosses a network boundary between the key owner, the CPU trust domain, and the GPU. F5 can sit on that path for mutual TLS, policy enforcement, and API gateway controls so confidential AI traffic is authenticated before it reaches Intel TDX or GPU execution.

NetAppNovember 10, 2026

Nebul Adopts NetApp Novus for Sovereign AI Factories

NetApp said Nebul, a European AI-native cloud provider, is the first neocloud to adopt NetApp Novus, now generally available. Novus is a high-performance architecture built on ONTAP, designed for up to 100 TB/s aggregate throughput and GPU utilization at AI-factory scale. Nebul is using it as the data layer of a sovereign platform that combines accelerated infrastructure, enterprise data services, and production AI, with both companies exploring how existing NetApp estates move into sovereign GPU clouds.

Source

F5 Relevance

Novus feeding sovereign GPU clusters is an S3 and file data-path problem at extreme throughput. F5 can secure and steer that path — TLS, WAF, and traffic management between enterprise clients, Nebul’s neocloud, and NetApp data services — without becoming the storage layer itself.

ScalityNovember 10, 2026

Scality Becomes a CVE Numbering Authority under ENISA

Scality announced on November 10, 2026 that it has joined the CVE Program as a CVE Numbering Authority under the ENISA root, effective July 21, 2026. It can now assign CVE IDs and publish records for vulnerabilities in RING, ARTESCA, and ADI, aligned with EU Cyber Resilience Act reporting that began September 11, 2026. The company is also moving previously disclosed issues from technical bulletins into CVE records so customer scanners and patch workflows can consume them.

Source

F5 Relevance

Scality’s S3 object stores sit on the same data path F5 already secures with ADSP and WAF. Authoritative CVE records for RING, ARTESCA, and ADI give F5 alliance engineers a cleaner signal for joint security advisories and for inspecting S3 API traffic in front of those platforms.
