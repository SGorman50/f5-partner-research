Nutanix Gives Enterprises the Freedom to Run Production Agentic AI Their Way

On August 26, 2026, Nutanix announced general availability of Nutanix Enterprise AI (NAI) 2.8 and upcoming Nutanix Kubernetes Platform (NKP) 2.19, expanding Nutanix Cloud Platform for production agentic AI. NAI 2.8 adds centralized inference control, a generally available Nutanix Agent Gateway with Model Context Protocol (MCP) for governing how agents connect to apps and data, and enhanced Nutanix Private Inference for fine-tuning, security, and governance. NKP 2.19, arriving soon, targets CNCF Kubernetes AI-conformant container management on bare metal and VMs with a built-in AI catalog for agentic applications.

https://www.nutanix.com/press-releases/2026/nutanix-gives-enterprises-the-freedom-to-run-production-agentic-ai-their-way

F5 Relevance

MCP-governed agent-to-app and agent-to-data traffic, plus Kubernetes-hosted inference, is a direct insertion point for F5 API gateway, identity-aware access, and NGINX Ingress. F5 can position BIG-IP, Distributed Cloud, and AI traffic management as the north-south and east-west control layer in front of Nutanix Agent Gateway and NKP clusters.

NVIDIA Announces Financial Results for Second Quarter Fiscal 2027

On August 26, 2026, NVIDIA reported Q2 FY2027 revenue of $96.2 billion, up 106% year over year and 18% sequentially, with Data Center revenue of $89.0 billion, up 117% year over year. GAAP and non-GAAP gross margins were both 75.0%; GAAP diluted EPS was $2.46. CEO Jensen Huang said AI has reached an inflection point and that Vera Rubin is now in full production to power accelerating AI-factory demand. NVIDIA guided Q3 revenue to about $108.0 billion (±2%) and returned approximately $26.0 billion to shareholders in the quarter.

https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027

F5 Relevance

Record data-center and Vera Rubin rack-scale production confirm that AI-factory Ethernet, GPU networking, and inference traffic will keep scaling. F5 should align BIG-IP, NGINX, Distributed Cloud, and AI traffic management (KV-cache-aware routing, API security, TLS) with NVIDIA Spectrum-X / BlueField deployments that partners such as Cisco, Dell, and Equinix are already packaging.

Red Hat Hardened Images Now Supported in AWS InspectorScan API and ECR Basic Scanning

On August 25, 2026, Red Hat said AWS InspectorScan API and Amazon ECR Basic scanning now support Red Hat Hardened Images. The integration is intended to cut vulnerability-alert noise from bloated base images, verify software supply-chain integrity, and streamline hybrid-cloud compliance for teams using enterprise open source container images. Red Hat framed the move as helping organizations pursue a lower-CVE, smaller-attack-surface starting point for container infrastructure.

https://www.redhat.com/en/blog/streamlining-container-security-red-hat-hardened-images-now-supported-aws-inspectorscan-api-and-ecr-basic-scanning

F5 Relevance

Hardened, continuously scanned container images are the runtime base for OpenShift and Kubernetes apps that F5 already fronts with NGINX Ingress, WAF, and API security. Joint stories around supply-chain provenance plus F5 runtime protection (WAF, bot, mTLS, API auth) are a practical OpenShift/AWS partnership motion.
