NetApp July 1, 2026

NetApp Announces StorageGRID 12.1 to Scale AI and Modern Workloads

NetApp announces StorageGRID 12.1 (July 1, 2026) with a Global Federated Namespace managing up to 10 exabytes across distributed StorageGRID systems — removing the need to re-architect applications at scale. Performance increases by up to 400% over StorageGRID 12.0 to deliver 12 TB/s of throughput for AI factory workloads. The release also adds batch operations on billions of objects, improved AI data pipeline change-tracking, and enhanced multi-admin verification for regulated environments.

F5 Relevance

StorageGRID 12.1's S3-compatible federated namespace and 12 TB/s throughput creates a high-speed object storage fabric ideal for AI data pipelines — exactly the type of large-scale S3 data flow where F5's API gateway, load balancing, and S3 traffic management capabilities can secure and optimize the path between AI compute clusters and distributed object storage.

Scality July 1, 2026

Scality & OVHcloud Launch Sovereign Storage Platform

Scality and OVHcloud announce a joint sovereign storage platform (July 1, 2026) combining Scality RING and ARTESCA S3-compatible object storage with OVHcloud's On-Prem Cloud Platform (OPCP). The solution targets European enterprises needing data sovereignty compliance (GDPR, DORA, NIS2, HIPAA) while enabling AI workloads including GPU Direct, MLOps, model training, and inference on-premises. An optional off-site backup tier uses OVHcloud HGR-STOR for private S3-compatible disaster recovery.

F5 Relevance

A sovereign AI storage stack built on S3-compatible object storage with GPU Direct support is a high-value intersection for F5's S3 traffic management and API gateway capabilities — particularly for securing and inspecting S3 API traffic flowing between AI compute and sovereign storage in regulated European environments where F5 Distributed Cloud's multi-cloud security posture is highly relevant.

Scality June 30, 2026

Scality and OVHcloud Build a Sovereign AI Storage Stack on OPCP and Bare Metal

StorageReview coverage (June 30, 2026) of the Scality + OVHcloud OPCP announcement provides technical depth: RING and ARTESCA are integrated at the hardware layer with GPU Direct compatibility for model training and inference, with OPCP providing cloud-native orchestration. F5 Relevance
