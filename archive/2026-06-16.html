CROWDSTRIKE June 15, 2026
CrowdStrike Unveils Continuous Identity for AI Agents

CrowdStrike launched Continuous Identity for AI Agents, a Falcon Next-Gen Identity Security capability replacing static policies with real-time, risk-aware authorization using SPIFFE-based verifiable identities. The system grants zero standing privilege — access is assigned only when needed and revoked immediately after, with Falcon AIDR monitoring agent prompts and intent for misuse. Addresses AI-specific risks including excessive privileges, compromised credentials, and unauthorized agent-to-agent delegation.

F5 RELEVANCE

CrowdStrike's AI agent identity model (SPIFFE, zero standing privilege, continuous authorization) maps directly to F5's OAuth/OIDC and identity-aware access capabilities. F5 can serve as the network-layer enforcement point — API gateway, mTLS termination, and zero-trust ingress — for policies that Falcon generates, creating a joint identity-to-network security story.
