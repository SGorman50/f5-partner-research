Cisco and NIIN Launch a Sovereign AI Cloud Prototype for Australian Universities

On November 10, 2026, Cisco, through Australia’s National Industry Innovation Network, launched a Sovereign AI Cloud prototype so universities, industry, and government can run sensitive AI research on locally governed infrastructure. Branded the AI Adoption Moonshot, it is framed as a response to Australia’s National AI Plan. Xenon and Sharon AI are contributing technical work on Cisco infrastructure, and an AI Skills Challenge aims to enable skills development for more than 200,000 Australians by mid-2028.

Source

F5 Relevance

Sovereign research clouds still need secure ingress, API policy, and data-residency controls between campus users and shared GPU services. F5 can position BIG-IP, NGINX, and Distributed Cloud as the policy and traffic layer in front of NIIN-style platforms.

KIOXIA and Dell Deliver a 157 PB Single-Rack Object Store

On November 11, 2026, KIOXIA and Dell Technologies announced a 157 PB object store in a single 42U rack, using 640 KIOXIA LC9 Series 245.76 TB SSDs across 16 PowerEdge R7725xd servers running Dell ObjectScale. The design targets AI training, data lakes, and other unstructured workloads, consolidating capacity so customers can cut footprint, power, and cooling versus HDD or lower-density flash at the same capacity.

Source

F5 Relevance

ObjectScale is an S3-class path for AI data lakes. F5 can secure and load-balance S3 API traffic into these dense racks, including TLS offload and API controls, without forcing unstructured data through a less efficient path.

Intel and Altera Plan a Real-Time Sensor Bridge for Edge and Physical AI

On November 10, 2026, Intel and Altera announced a collaboration to build a flexible, real-time sensor bridge for healthcare, aerospace and defense, and robotics. The plan combines Intel compute, connectivity, and software with Altera FPGAs so OEMs can stream diverse sensor data into host memory and move from prototype to deployment through Intel’s Open Edge Platform SDK and an Altera SDK.

NVIDIA Donates OpenShell to the CNCF and Adds Kubernetes AI Factory Tools

At KubeCon on November 10, 2026, NVIDIA said it is contributing OpenShell, its open-source runtime for securing and governing autonomous agents, to the Cloud Native Computing Foundation as a Sandbox project, and contributing to Google-led Agent Substrate for long-running agent workloads on Kubernetes. It also previewed NVIDIA Kubernetes Engine, Kubernetes Recipes, and NVIDIA Snapshot in the DSX AI Factory Platform.

Source

Red Hat and NVIDIA Detail OpenShell’s Deny-by-Default Controls at KubeCon

SiliconANGLE reported on November 11, 2026 from KubeCon that Red Hat and NVIDIA expanded their OpenShell work so AI agents cannot reach secrets, use deny-by-default networking, and leave a policy record of actions.
