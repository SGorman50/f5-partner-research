CISCONovember 23, 2026

Cisco and OpenAI Launch Shirudo to Safeguard Agentic AI

On November 23, 2026, Cisco and OpenAI launched Shirudo, an open-source project that uses eBPF to drop signed security shields into a running Linux kernel without a reboot. The aim is self-defending infrastructure: AI agents find vulnerabilities, generate shields, and test them while people keep policy control.

Source

F5 RELEVANCE

Shirudo moves agent defense into the kernel. F5 can sit in front of those hosts with API gateway, WAF, and Distributed Cloud controls so agent traffic is inspected at the edge before it reaches an eBPF shield.
