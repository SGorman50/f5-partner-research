CiscoSeptember 29, 2026

Bell and Cisco Sign MOU for Sovereign AI Infrastructure in Canada

On September 29, 2026, Bell Canada and Cisco announced a memorandum of understanding to build a sovereign AI infrastructure offering in Canada. The design pairs Bell data centers, connectivity, and operations with Cisco AI PODs, security, observability, and Sovereign Critical Infrastructure, including options for air-gapped or hybrid deployment of training and inference. The target is government and regulated workloads that must stay in Canada.

F5 relevance. Sovereign AI PODs are a joint-solution surface for F5: BIG-IP and Distributed Cloud can front Cisco AI POD ingress with WAF, API security, and DDoS controls while keeping traffic inside the Canadian trust boundary Bell is selling.
HPE GreenLakeSeptember 29, 2026

HPE Will Integrate NVIDIA OpenShell into Private Cloud AI

HPCwire reported on September 29, 2026 that HPE is expanding its NVIDIA work so enterprises can control how autonomous agents touch data, apps, and infrastructure. A planned integration of generally available NVIDIA OpenShell with HPE Private Cloud AI will enforce access policies, monitor agent activity, and keep auditable records across agent frameworks. Availability is planned for Q4 2026 across the AI Factory portfolio, including sovereign deployments.

F5 relevance. OpenShell on HPE Private Cloud AI is a runtime policy plane, not an ingress plane. F5 NGINX and BIG-IP can sit in front of those agent APIs to enforce identity, rate limits, and WAF controls on the calls OpenShell allows out of the sandbox.
IntelSeptember 29, 2026

Intel Agent Toolkit Adds NVIDIA OpenShell Policy Sandboxes

Intel's newsroom published that the Intel AI for Enterprise Agent Toolkit now offers NVIDIA OpenShell as an optional, policy-enforced sandbox for agent actions, access, and credentials. OpenShell runs agents in YAML-governed sandboxes with default-deny egress and can sit inside Intel TDX confidential VMs on Kubernetes. The publicnow syndication of the same Intel item is dated September 29, 2026. This is a product integration, not a new silicon announcement.

F5 relevance. Xeon-hosted agents with OpenShell still call enterprise APIs. F5 can be the identity-aware gateway (OAuth, mTLS, API security) in front of those tool calls, complementing TDX isolation rather than competing with it.
NetAppSeptember 29, 2026

NetApp Launches Novus File System for GPU AI Streaming at Insight

At NetApp Insight on September 29, 2026, NetApp introduced Novus, a file system it claims is the fastest for streaming large data sets to GPUs. Novus separates metadata and data servers so performance, capacity, and concurrency scale independently under one NFS namespace, aimed at neoclouds and GPU-as-a-service AI factories. The same event expanded the AI Data Engine's metadata discovery across ONTAP, StorageGRID, and non-NetApp stores, and added Keystone Sovereign controls. Blocks & Files notes this follows last week's intent to acquire PEAK:AIO.

F5 relevance. Novus and StorageGRID-aware metadata discovery put high-throughput NFS and S3 paths in front of GPU clusters. F5 can secure and steer those data and API flows — S3 access policy, TLS, and multi-cluster load balancing — without sitting in the RDMA data path.
NutanixSeptember 29, 2026

Nutanix and NetApp Pair AHV with ONTAP for VMware Exit Paths

On September 29, 2026, Nutanix described a joint solution that pairs Nutanix Cloud Infrastructure and the AHV hypervisor with NetApp ONTAP over NFS, planned for this fall. Customers can keep AFF and FAS arrays while moving the virtualization layer off VMware. Nutanix Move will automate migrations, and NetApp Shift Toolkit support is expected for zero-copy moves that do not relocate data. Live demos are at NetApp Insight.

F5 relevance. A split compute-and-storage design increases east-west and NFS/API traffic between AHV clusters and ONTAP. F5 BIG-IP and NGINX Ingress are the natural policy point for the application and Kubernetes services those migrated workloads expose.
Red HatSeptember 29, 2026

Red Hat Backs OpenClaw Enterprise as an Open Agent Control Plane

On September 29, 2026, Red Hat VP Joe Fernandes wrote that Red Hat is contributing to OpenClaw and the newly announced OpenClaw Enterprise, an open-source control plane for deploying and operating persistent agents across users and teams. Red Hat, NVIDIA, and others are building it in the open, following the same upstream pattern Red Hat used for Linux and Kubernetes. The post frames OpenClaw Enterprise as the layer above sandboxing, AI gateways, and AgentOps.

F5 relevance. An open agent control plane on OpenShift will concentrate model, tool, and agent-to-agent traffic. F5 NGINX and Distributed Cloud can be the external gateway and WAF for that control plane, especially where customers already run OpenShift ingress on NGINX.
