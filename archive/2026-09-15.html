Red Hat Issues Ansible-core Security Update for CVE-2026-11332 on RHEL 9.4 SAP

On September 14, 2026, Red Hat published RHSA-2026:67467, an Important ansible-core update for Red Hat Enterprise Linux 9.4 Update Services for SAP Solutions. The advisory covers CVE-2026-11332, an argument-injection flaw in ansible-galaxy role install: a malicious role author can inject git configuration flags via the src field in meta/requirements.yml and achieve arbitrary code execution when an operator installs the role. Red Hat rates the update Important; exploitation requires the user to install a crafted role.

Red Hat Advisory RHSA-2026:67467

F5 Relevance

Many F5 customers drive BIG-IP, NGINX, and Distributed Cloud changes through Ansible. A Galaxy-role RCE is a supply-chain risk on the automation plane that can rewrite ADC, WAF, and certificate policy. Treat role sources as trusted code and patch ansible-core on SAP/RHEL control nodes that touch F5 estates.

CiscoSeptember 14, 2026

Cisco Warns of Actively Exploited Root RCE in Secure Email Gateway (CVE-2026-76461)

On September 14, 2026, Cisco published a critical advisory (CVSS 9.8) for CVE-2026-76461, an unauthenticated email-parsing issue in AsyncOS on Cisco Secure Email Gateway. A crafted email carrying malicious SQL can execute arbitrary commands as root on physical and virtual appliances in any configuration. Cisco PSIRT observed exploitation in September 2026; CISA added the CVE to KEV with a September 17 federal patch deadline. There are no workarounds. Fixed AsyncOS releases include 15.5.5-014, 16.0.4-302, and 16.5.0-780. Secure Email and Web Manager and Secure Web Appliance are not affected.

Cisco Security Advisory cisco-sa-esa-inj-2bLVGmhX

F5 Relevance

Email security appliances sit on the same inbound path as F5 BIG-IP SSL inspection and SMTP load balancing. Joint customers should treat this as an adjacent-perimeter incident: confirm ESA versions, inspect north-south mail flows on F5, and watch for unexpected outbound connections from mail gateways after a root compromise.

IntelSeptember 14, 2026

Researchers Disclose DDRop Attack Against Intel TDX Confidential Computing

On September 14, 2026, researchers from KU Leuven, ETH Zurich, Durham University, and Google disclosed DDRop, a sub-$200 DDR5 hardware interposer that silently drops memory writes so encrypted pages decrypt as stale data. The missing freshness property in Intel TDX, Intel Scalable SGX, and AMD SEV-SNP can let an attacker with physical access interfere with protected VMs and, on TDX, forge attestation. Disclosure was coordinated with Intel and AMD; vendors treat physical DRAM attacks as out of scope for current products. The Register covered the research the same day.

The Register — DDRop hardware attack

F5 Relevance

Confidential AI and TEE-backed inference are a standing F5, Intel, and NVIDIA topic. If TDX attestation can be forged at the DIMM, F5 should not treat TEE quotes as a complete trust boundary for API and WAF policy—pair confidential compute with network identity, mTLS, and runtime inspection.

NVIDIA Expands CUDA-Q with Logical Layer for Fault-Tolerant Quantum Computing

On September 14, 2026, NVIDIA announced CUDA-Q Logical, an open-source orchestration layer on the CUDA-Q platform for designing and testing fault-tolerant quantum applications in areas such as drug discovery, financial modeling, and materials. Fermilab reported a 7x speedup, cutting fault-tolerant architecture work from five months to three weeks. Sandia National Laboratories’ QUOPS benchmark for fault-tolerant hardware readiness is now available in CUDA-Q. The stack targets hybrid CPU, GPU, and QPU workflows.

NVIDIA Newsroom — CUDA-Q Logical

F5 Relevance

Hybrid classical-quantum workflows will traverse GPU clusters, HPC fabrics, and job APIs. F5 can secure and load-balance the classical front end of CUDA-Q services as quantum orchestration becomes another high-value east-west path in AI factories.
