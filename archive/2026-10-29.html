NvidiaOctober 27, 2026

NVIDIA and Oracle Expand Vera Rubin to Multi-Gigawatt Scale and Bring Vera CPUs to OCI

On October 27 at Oracle AI World, NVIDIA and Oracle said Vera Rubin NVL72 systems will scale to multi-gigawatt OCI Superclusters, and that Vera Rubin NVL72 plus NVIDIA Vera CPUs are generally available on OCI. Vera CPUs are positioned for the CPU-heavy work agents do between model calls — executing tools, testing code, and retrieving data — so CPU and GPU capacity can scale independently. OCI Superclusters combine NVL72 racks, Spectrum-X Ethernet, and BlueField-4 DPUs. Oracle also plans HGX Rubin NVL8. OpenAI is cited as already training and serving frontier models, including GPT-6 Astra, on OCI Superclusters.

F5 relevance

Multi-gigawatt Vera Rubin clusters plus a separate Vera CPU tier for agent tool-use is the split F5’s AI traffic management is built for: route inference to GPUs, route tool and API calls through a governed gateway, and terminate TLS at the edge of the cluster.

CiscoOctober 28, 2026

Cisco AI Defense Joins ServiceNow’s Control Tower Alliance as a Founding Member

On October 28, Cisco joined ServiceNow’s Control Tower Alliance as a founding member so customers who govern AI in ServiceNow can plug Cisco AI Defense in as the security engine. The integration covers AI asset discovery, supply-chain scanning of models and MCP servers, AI red-teaming, and runtime protection for applications and agents. NVIDIA, Anthropic, AWS, OpenAI, and Okta are also named among the founding members.

F5 relevance

Control Tower is a policy plane in front of models, agents, and MCP servers — the same path F5 already secures with AI Gateway, WAF, and identity-aware access. F5 can be the inline enforcement point the Control Tower calls when an agent is allowed to act.

IntelOctober 27, 2026

Intel and Oracle Plan a Multiyear Collaboration for Enterprise and Agentic AI on OCI

On October 27 at Oracle AI World, Intel and Oracle said they will expand Intel Xeon-based computing on Oracle Cloud Infrastructure for enterprise applications, agentic AI, and inference. Planned OCI X14 offerings are expected to use Intel’s next server processor, Diamond Rapids, with AMX and APX aimed at embedding generation, reranking, and smaller-model inference next to AI agents.

F5 relevance

Agent orchestration on Xeon is a new flow of tool calls, retrieval, and inference beside GPU racks. F5’s AI traffic management and API gateway are a control point in front of those OCI agent services, independent of whether the accelerator is NVIDIA or Intel.

HPE GreenLakeOctober 27, 2026

HPE Unifies Visibility Across Wired, Wireless, and SASE from Edge to Cloud

On October 27, HPE said it will operate EdgeConnect SD-WAN and SSE inside HPE Mist and Aruba Central so NetOps and SecOps share one view from campus and branch through WAN to cloud. The Marvis agentic AI layer is meant to detect and fix experience issues for apps such as Zoom and Teams. Mist integration is planned for calendar 2026; Aruba Central integration for the first half of calendar 2027.

F5 relevance

A single control plane over SD-WAN, SSE, and campus wireless still needs an application delivery and security layer for the SaaS and private-app traffic it steers. F5 Distributed Cloud and BIG-IP can sit beside EdgeConnect, especially where GreenLake customers already run F5 in the data center.

NetAppOctober 27, 2026

Nutanix Cloud Platform with NetApp ONTAP Is Now Available

On October 27, Nutanix said the joint configuration is available, pairing Nutanix Cloud Infrastructure and AHV with NetApp ONTAP over NFS so customers can modernize virtualization without replacing AFF or FAS arrays. Nutanix Move handles migration; NetApp Shift Toolkit support is still forthcoming. This is the availability step after the April 2026 alliance announcement.

F5 relevance

A production Nutanix-on-ONTAP stack still needs ingress, load balancing, and API security for the apps that move with it. F5 can attach BIG-IP or Distributed Cloud to the new AHV clusters without touching the ONTAP data plane.

Epic Says Nationwide Diagnostic Image Exchange Is Possible with TEFCA

On October 27, Epic’s interoperability director argued that TEFCA can carry nationwide diagnostic image exchange. Epic’s standards-based image exchange is already rolling out, and clinicians will be able to view high-resolution DICOM images across providers starting with Epic customers in November, if other EHRs, PACS, and VNAs adopt the same open framework.

F5 relevance

A national DICOM/FHIR image exchange is a latency-sensitive, identity-bound traffic flow between health systems. F5 can offer the ingress, TLS, and API gateway layer in front of Epic image endpoints, plus WAF and DDoS controls.
