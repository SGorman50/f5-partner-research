AristaSeptember 23, 2026

CISA Deadline Hits Today for Actively Exploited Arista VeloCloud Flaw (CVE-2026-93952)

Arista disclosed CVE-2026-93952 on September 22 as a CVSS 10.0 input-validation flaw in on-prem VeloCloud Orchestrator that allows unauthenticated privileged access when certificate-based Edge authentication is in use. CISA added it to the Known Exploited Vulnerabilities catalog the same day and set a federal remediation deadline of September 25, 2026. Patches are available for the 5.2.3 and 6.4.2 trains (5.2.3.16 and 6.4.2.8); some older trains still need TAC guidance. This is a follow-on operational update to the September 22 advisory, focused on the deadline and patch status.

Source

F5 RELEVANCE

SD-WAN orchestrators are a control plane in front of branch traffic. F5 can pair BIG-IP and Distributed Cloud WAAP with patched VeloCloud edges so customers have an independent policy and DDoS layer while they close this actively exploited hole.

CiscoSeptember 25, 2026

Researchers Disclose Pre-Auth RCE in the TACACS+ Protocol Cisco Originated

Risky Business reported on September 25 that Elttam researchers found a pre-authentication remote code execution flaw in TACACS+, the 1993 Cisco authentication, authorization, and accounting protocol still used on network gear over port 49. The attack needs only a small number of packets and can be aimed at TACACS+ servers directly. Patches exist for the maintained Shrubbery Networks fork; a CVE had not been assigned at publication, and Cisco has not actively updated the original implementation for years. State-linked actors have previously abused TACACS+ weaknesses against telecoms.

Source

F5 RELEVANCE

AAA protocols sit next to F5 device and API access control. F5 engineers can use this disclosure to push customers off legacy TACACS+ toward modern identity (OIDC/SAML) in front of BIG-IP and NGINX management planes, and to review any TACACS+ still fronting partner network gear.
