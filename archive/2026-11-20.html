DXC embeds Cisco AgenticOps into OASIS for Meraki Wi-Fi

DXC Technology said on November 19 that it is integrating Cisco AgenticOps into DXC OASIS, its orchestration platform that pairs agentic AI with human oversight. The first use case is workplace Wi-Fi performance in Cisco Meraki environments, with a stated path to broader AI-driven operations. The release frames the work as turning network insights into governed incident action rather than a new Cisco product launch.

Source

F5 Relevance

Agentic network operations on Meraki is another place F5 can sit in the action path: policy enforcement, API security, and traffic steering between the insight layer and the systems that actually change the network.

CrowdStrikeNovember 19, 2026

Jamf puts Apple device management apps on Falcon Foundry

Jamf announced on November 19 that its Apple management and security apps, including a Resilience Platform app and connectors for Next-Gen SIEM and Charlotte SOAR, are available on CrowdStrike Falcon Foundry. Falcon detections can now trigger Jamf actions such as device lockdown, passcode clears, and inventory updates inside existing Falcon workflows. The apps are available now in the CrowdStrike Marketplace and Falcon Unified Content Library.

Source

F5 Relevance

Closing the gap between a Falcon detection and a device action is an identity-and-access pattern F5 already sees in zero-trust designs. Joint stories can cover how BIG-IP and NGINX enforce the same least-privilege path for Apple fleets that Falcon and Jamf now automate.

DellNovember 19, 2026

Dell and Microsoft expand private AI closer to the data

Network World reported on November 19 that Dell and Microsoft are extending their private-cloud work so AI inference can run in the customer data center. The stack pairs Dell Private Cloud with Azure Local and Foundry Local, plus Nvidia acceleration, including PowerEdge XE9780 servers with Nvidia HGX and support for HGX B300 through Azure Local. The pitch is data residency and lower reliance on public-cloud APIs, with Dell citing potential total-cost reductions of up to 90 percent over two years for some configurations.

Source

F5 Relevance

Private inference on Dell plus Azure Local still needs a secure front door for model APIs, GPU traffic, and east-west service calls. F5 can position BIG-IP and Distributed Cloud as the policy and load-balancing layer for those on-prem AI endpoints.

Telecompaper reported on November 19 that France-IX opened a new point of presence at Equinix PA3 in Saint-Denis, north of Paris. IntelNovember 19, 2026

Intel and Microsoft harden the AI PC for agentic workloads

Intel published on November 19 a joint security note with Microsoft for Windows 11 Pro on Intel vPro. Microsoft Defender AI Agent Runtime Protection, in preview, inspects agent prompts in real time. BitLocker is paired with Intel Total Storage Encryption, which Intel says cuts CPU load by about 70 percent versus software-only encryption, and Intel Threat Detection Technology uses CPU telemetry to spot malicious activity.

Source

F5 Relevance

Endpoint agent controls do not replace the network policy those agents still need when they call enterprise APIs. F5 can extend the same least-privilege model from the vPro PC to BIG-IP and NGINX, so an agent that passes local checks is still constrained in transit.

MinIONovember 18, 2026

MinIO certifies AIStor as Datadog's on-premises log lakehouse

MinIO announced on November 18 a partnership that makes AIStor the first high-performance on-premises lakehouse certified for Datadog Bring Your Own Cloud logs. Customers keep logs in their own environment, with encryption and KMS under their control, and only query results go to Datadog. AIStor Tables adds Apache Iceberg so logs can sit with other structured and unstructured data. The offering is available now.

Source

F5 Relevance

A sovereign observability lakehouse still moves a lot of S3 and query traffic between collectors, AIStor, and Datadog. F5 can secure and shape that path with S3-aware access control, TLS, and load balancing so telemetry stays local without becoming a new exposure.

NVIDIANovember 20, 2026

NVIDIA is in advanced talks to buy diffusion-model startup Inception

Tech Funding News, citing The Information, reported on November 20 that NVIDIA is in advanced talks to acquire Inception, a Palo Alto startup building diffusion language models, for more than $500 million. The report says the three co-founders, including Stanford professor Stefano Ermon, would join NVIDIA, with employee earnouts still under discussion. Neither company has confirmed the deal. Inception raised a $50 million seed round in November 2025 that included NVIDIA's NVentures.

Source

F5 Relevance

A diffusion-model buy would pull faster parallel token generation into NVIDIA's software stack, which changes inference traffic patterns F5 already plans for. If the deal closes, KV-cache routing and API gateway controls become more relevant on Nemotron-class serving paths.

NVIDIANovember 19, 2026

NVIDIA and Microsoft extend Vera Rubin and confidential computing on Azure

NVIDIA said at Microsoft Ignite that Vera Rubin NVL72 systems are running in Azure, with expanded access to those VMs plus open models and customization in Microsoft Foundry. The companies are also extending confidential computing to bare-metal and rack-scale AI so models and data stay protected while they are processed. Microsoft is using NVIDIA Dynamo for post-training and RTX PRO 6000 Blackwell GPUs for Bing search models.

Source

F5 Relevance

Rack-scale Vera Rubin on Azure, plus confidential computing, is a deployment pattern F5 should design for: encrypted inference paths, multi-tenant API gateways, and traffic management that does not break attestation.
