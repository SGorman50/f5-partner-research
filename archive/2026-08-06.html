Equinix August 5, 2026

All Nippon Airways Builds Cloud Network Hub with Equinix

On August 5, 2026, Equinix announced that All Nippon Airways (ANA) has built a centralized cloud network hub on Equinix Fabric to support next-generation passenger services including reservations, boarding, customer communications, and operational systems. Facing a projected 10x increase in global data volumes, ANA cut network provisioning time by roughly 80% and is targeting a 30% reduction in five-year total cost of ownership. The software-defined interconnection enables on-demand, secure connectivity to AWS, Microsoft Azure, and Google Cloud without extra physical circuits, freeing capacity for application development, testing, analytics, automation, and AI workloads.

Airline multicloud hubs concentrate high-value application and API traffic across private interconnects to hyperscalers — a natural placement for F5 BIG-IP, Distributed Cloud, and API security to enforce zero-trust access, TLS, and app delivery at the Equinix edge. F5 can position joint reference architectures with Equinix Fabric for regulated industries modernizing passenger and operational platforms.

Nvidia August 4, 2026

As AI Increases Demands on Memory, Storage Steps Up — NVIDIA at FMS 2026

On August 4, 2026, NVIDIA published a Future of Memory and Storage (FMS) briefing on AI-native storage infrastructure. The company highlighted open-sourcing cuFile APIs (GPUDirect Storage) so GPUs can read/write storage directly, and launched Storage-Next with industry partners plus the SCADA (scaled, accelerated data access) framework to feed GPUs only the data they need from storage. Benchmarks show the NVIDIA Vera CPU in Vera BlueField-4 STX delivering up to 3.21x higher throughput than x86 in a two-stage compression and encryption pipeline, underscoring in-silicon security and data-path offload for agentic AI workloads that generate thousands of concurrent storage operations.

Read source →

F5 Relevance

Direct GPU-to-storage paths, S3/object data flows, and BlueField-4 STX encryption/compression pipelines are core F5 adjacency: AI factory traffic still needs secure north-south and east-west delivery, API gateway controls, and inspection at the storage/network boundary. F5 can align AI traffic management, NGINX, and partner plays with MinIO/NetApp/Scality on NVIDIA Storage-Next and GPUDirect Storage architectures.
