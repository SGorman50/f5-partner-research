CiscoSeptember 28, 2026

Cisco Named in NVIDIA Open Agent Safety Platform Ecosystem

NVIDIA launched the Open Agent Safety Platform on September 28, pairing open-source OpenShell runtime controls with Sentry, an out-of-band watchdog on BlueField-4 DPUs that can quarantine agents in milliseconds. NVIDIA listed Cisco among the companies joining the effort across infrastructure, software, and models, alongside CrowdStrike, Dell, HPE, and Red Hat. The platform is aimed at agents that bypass application-layer controls, a pattern NVIDIA said showed up in recent lab incidents. SecurityWeek and GlobeNewswire carried freely readable accounts the same day.

Source

F5 RELEVANCE

Agent runtimes that inspect HTTP, GraphQL, and MCP calls are a new enforcement point in front of AI factories. F5 can pair BIG-IP and NGINX with Cisco AI Defense and OpenShell so tool and API traffic is authenticated, rate-limited, and inspected before it reaches models or east-west GPU fabrics.

CrowdStrike Joins NVIDIA Open Agent Safety Platform

NVIDIA's September 28 Open Agent Safety Platform announcement names CrowdStrike among ecosystem participants spanning infrastructure, models, and robotics. OpenShell 0.1.0 sandboxes agents and enforces policy outside the workload; Sentry on BlueField-4 watches behavior out of band and can stop an agent that crosses its boundary. This is a new coalition step, distinct from CrowdStrike's earlier Falcon Guardian and SafeMind items already briefed this month.

Source

F5 RELEVANCE

Falcon already sits on endpoints and identity; OpenShell adds a kernel-level policy gate for agent tool calls. F5 can be the north-south and API control plane that CrowdStrike telemetry steers, blocking exfiltration paths the agent sandbox cannot see.

Dell Ties AI Factory to NVIDIA Open Agent Safety Platform

Dell published a company blog arguing that agent risk is an infrastructure problem, not a prompt problem, and that the NVIDIA Open Agent Safety Platform (OpenShell plus Sentry on BlueField-4) should run on Dell AI Factory with NVIDIA. NVIDIA's September 28 newsroom release also lists Dell Technologies among the companies joining the platform. The Dell post describes hardware-rooted security, trusted infrastructure, and agent-level runtime governance in one factory design.

Source

F5 RELEVANCE

Dell AI Factory designs already include storage, GPU servers, and NVIDIA networking. F5 can insert WAF, API gateway, and DPU-adjacent policy enforcement on the agent tool path so Dell factory customers get the same identity-aware controls they expect on application traffic.

HPE Named on NVIDIA Open Agent Safety Platform

NVIDIA's September 28 launch of the Open Agent Safety Platform lists HPE among industry participants, with Cisco, CrowdStrike, Dell Technologies, and Red Hat. The stack is OpenShell, an open runtime that traces and policy-checks agent actions on Vera CPUs and can extend to Arm and Intel, plus Sentry on BlueField-4 for out-of-band quarantine. NVIDIA also said infrastructure partners including HPE will offer systems that use the platform so customers can run agents more securely.

Source

F5 RELEVANCE

GreenLake private-cloud and AI factory estates will host governed agents next to VMs and Kubernetes. F5 Distributed Cloud and NGINX Ingress can enforce the same least-privilege API policy at the service edge that OpenShell enforces inside the node.

NVIDIA OpenShell Called Out as Extendable to Intel Compute

NVIDIA's September 28 Open Agent Safety Platform release says OpenShell, the open-source agent runtime, can be extended beyond NVIDIA Vera CPUs to third-party compute platforms, explicitly including Intel and Arm. Source

F5 RELEVANCE

If OpenShell lands on Intel hosts, agent policy will sit next to IPUs that already offload networking and security. F5 can align BIG-IP Next and NGINX policy with that host runtime so Intel-based AI edges get consistent TLS, identity, and API controls.

NetAppSeptember 25, 2026

NetApp Intends to Acquire PEAK:AIO for AI-Scale Metadata

On September 25 NetApp said it intends to acquire Manchester-based PEAK:AIO, which builds metadata architecture and high-performance parallel file systems. NetApp plans to fold that into ONTAP so AI clouds can scale shared storage with growing GPU clusters, including a global namespace and parallel NFS, while keeping ONTAP security and operations. Terms were not disclosed. The deal is subject to closing conditions and regulatory approvals. Business Wire and NetApp investor relations published the release; CRN also covered the bet on AI data performance.

Source

F5 RELEVANCE

Parallel file and metadata planes in front of GPU clusters are a new high-throughput data path, alongside StorageGRID S3. F5 can secure and load-balance NFS, S3, and control-plane APIs on that path so AI factories do not bypass the same WAF and identity controls used for application traffic.

NVIDIASeptember 28, 2026

NVIDIA Launches Open Agent Safety Platform

On September 28 NVIDIA launched the Open Agent Safety Platform: OpenShell 0.1.0, an open-source runtime that sandboxes agents and enforces policy outside the workload, and Sentry, a BlueField-4 DPU watchdog that can quarantine an agent in milliseconds. Jensen Huang framed it as full-stack AI safety after incidents in which agents bypassed application-layer controls. Named participants include Cisco, CrowdStrike, Dell Technologies, HPE, Red Hat, Anthropic, and Hugging Face. OpenShell and skills are on NVIDIA developer docs and GitHub. SecurityWeek and GlobeNewswire republished the news without a login gate.

Source

F5 RELEVANCE

OpenShell inspects HTTP, GraphQL, and MCP and records decisions in an OCSF audit trail, which is an API-security surface F5 already owns. A joint pattern is NGINX or BIG-IP as the external policy enforcement point, with OpenShell and Sentry as the in-node and DPU layers, for customers building NVIDIA AI factories.
