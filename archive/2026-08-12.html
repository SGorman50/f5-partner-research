CrowdStrike Named a Leader in the 2026 IDC MarketScape for Enterprise MDR/MXDR

HPE and EigenQ Partner on Practical Post-Quantum Security Retrofits for Existing Servers

Covered August 9, 2026 from Black Hat USA, HPE and EigenQ described a channel-delivered partnership to help defense, critical infrastructure, healthcare, and financial customers meet accelerating post-quantum cryptography mandates. EigenQ’s PCIe-based retrofit can be added to existing HPE servers without a rip-and-replace cycle or performance interruption, and is distributed with partners such as TD SYNNEX. HPE frames the work through its Quantum Scaling Alliance membership and HPE Labs focus on making quantum-resistant security operationally practical.

NutanixAugust 10, 2026

Nutanix Launches Open-Source MCP Server to Let Enterprise AI Agents Operate Hybrid Cloud

On August 10, 2026, Nutanix made an open-source Model Context Protocol (MCP) server available for Nutanix Cloud Platform, enabling agentic AI tools such as GitHub Copilot, Claude Code, and Cursor to drive hybrid-cloud operations through the Prism v4 API. The server acts as a secure passthrough that enforces existing RBAC, throttling, auditing, asynchronous task controls, and human-in-the-loop oversight so natural-language requests become precise infrastructure actions without bypassing enterprise security policy.

F5 Relevance

MCP-mediated agent control planes create a new north-south and east-west API surface between AI assistants and infrastructure control APIs. F5 API gateway, identity-aware access, and AI Guardrails capabilities can help customers authenticate agents, inspect MCP tool calls, rate-limit automation, and prevent prompt/tool abuse in Nutanix hybrid environments.

NvidiaAugust 11, 2026

NVIDIA Releases Nemotron 3.5 Lightning Open MoE Model for High-Volume Agentic Execution

On August 11, 2026, NVIDIA introduced Nemotron 3.5 Lightning, an open 30B mixture-of-experts model with 3B active parameters optimized for the high-volume execution layer of always-on AI agents—tool calls, result validation, and subagent delegation. The release emphasizes speculative decoding, harness-optimized training for stacks such as OpenClaw/Hermes/NemoClaw, and NVFP4/BF16 checkpoints claiming up to 4x output speed versus similar-sized models. NVIDIA also introduced NeMo Switchyard, an open routing library that directs each task to the best model by quality, latency, and cost.

Source ↗
F5 Relevance

Multi-model agent runtimes and Switchyard-style routers increase demand for low-latency, policy-aware AI traffic management between planners, executors, tools, and data stores. F5 AI Guardrails, NGINX/API gateway controls, and inference delivery can secure and shape these agent execution paths across NVIDIA-accelerated factories and enterprise edges.
