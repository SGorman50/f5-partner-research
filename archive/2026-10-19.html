Nvidia · October 16, 2026

NVIDIA RTX Spark Laptops Ship With Local Agents, OpenShell, and Home-Network Inference

NVIDIA said October 16 that RTX Spark laptops are available from ASUS, Dell, HP, Lenovo, Microsoft, and MSI. The systems pair a Blackwell RTX GPU and Grace CPU with up to 128GB of unified memory and up to 1 petaflop of FP4 AI compute so developers can run frontier models and local agents on a Windows laptop. Day-one software includes the NVIDIA OpenShell secure runtime and Microsoft Execution Containers for agent permission control, plus NVIDIA PAIR, which lets an RTX Spark PC serve inference to other Windows, Linux, and macOS machines on a home network. Adobe Photoshop, Premiere, and Substance 3D gain TensorRT acceleration on the same platform.

F5 Relevance

Local agents that call tools and then hand inference to other machines over the LAN create a new delivery and security edge. F5 can extend API gateway, identity, and AI traffic controls from the data center to that agent path so OpenShell policies and enterprise guardrails stay consistent when PAIR or similar routers expose model endpoints beyond a single laptop.
