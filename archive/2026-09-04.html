Nvidia
September 3, 2026

NVIDIA Agrees to Acquire Hugging Face for $12.93 Billion

NVIDIA announced on September 3, 2026 that it has agreed to acquire Hugging Face for $12.93 billion, one of its largest software deals after Groq. Hugging Face hosts more than 3 million models used by 18 million developers and 200,000 companies. NVIDIA says the platform will remain open, multi-cloud, and multi-accelerator, and that NVIDIA compute will not be required. Freely readable coverage from NVIDIA and BBC confirms about $11.9 billion cash to investors plus up to $1 billion in employee equity incentives.

https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/

F5 Relevance

Hugging Face is a primary distribution and inference front door for open models. NVIDIA owning that plane concentrates model serving, token traffic, and agent toolchains that F5 already sits in front of with BIG-IP, NGINX, API security, and AI traffic management. Partnership opportunities expand around securing Hugging Face-hosted inference, MCP/tool traffic, and multi-cloud model delivery.

Cisco
September 3, 2026

Cisco Partners with OpenAI to Bring Daybreak into AI Defense Skill and MCP Scanners

On September 3, 2026, Cisco said it is partnering with OpenAI to bring Daybreak into its AI security portfolio, starting with scanners that inspect Agent Skills and MCP servers. Cisco is validating a tiered architecture: Daybreak Blue for cybersecurity-tuned first-pass reasoning without refusal-driven blind spots, and Daybreak Red for obfuscated payloads and exploit chains. New skill-scanner and mcp-scanner run at marketplace ingestion, pre-install/pre-commit, and continuously afterward, targeting supply-chain attacks where executable code is bundled inside markdown skills.

https://blogs.cisco.com/ai/your-agent-trusts-things-you-never-approved

F5 Relevance

Agent Skills and MCP servers are becoming the new package ecosystem in front of APIs and inference gateways. F5 can complement Cisco AI Defense by inspecting and governing MCP/tool traffic, applying WAF/API security at the trust-grant points, and jointly positioning identity-aware access for non-human agents.

Ansible
September 4, 2026

Red Hat Shows AI-Assisted Firewall Change Workflows on Ansible Automation Platform

A September 4, 2026 Red Hat Developer article details an event-driven Ansible Automation Platform workflow that takes a ServiceNow firewall request, uses an LLM to propose rules and path analysis, then deploys only after dual human approvals in GitHub and ServiceNow. Event-Driven Ansible orchestrates ServiceNow, GitHub, the model, and Palo Alto firewalls. The AI never connects to devices or sees credentials; Ansible remains the deterministic execution layer with idempotent playbooks and audit trails.

https://developers.redhat.com/articles/2026/09/04/build-ai-assisted-firewall-workflows-ansible-automation-platform

F5 Relevance

The pattern—AI proposes, humans approve, automation executes—maps directly to F5 BIG-IP/NGINX policy changes, WAF rule updates, and API gateway config. Joint solutions could use Ansible as the trusted execution layer for F5 estate changes triggered by tickets, with F5 telemetry feeding the analysis step.

NetApp
September 3, 2026

NetApp and AWS Add FSx for ONTAP as an AWS Transform Migration Target

On September 3, 2026, NetApp and AWS announced general availability of Amazon FSx for NetApp ONTAP as a target in AWS Transform, AWS's agentic AI migration service. Enterprises can now migrate attached storage and database workloads directly to FSx for ONTAP in the same wave as compute and networking, instead of using intermediate storage hops. NetApp says the combination reduces migration time, cost, and risk while preserving application data access patterns.

https://www.netapp.com/newsroom/press-releases/news-rel-20260903-284784/

F5 Relevance

Storage migrations still move application and data-path traffic across hybrid networks. F5 can secure and accelerate those cutovers—load balancing, SSL, API, and S3/data-in-flight controls—as workloads land on FSx for ONTAP and remaining on-prem ONTAP/StorageGRID estates stay connected.
