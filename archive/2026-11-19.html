Ansible community package 15.0.0 ships on ansible-core 2.22

The Ansible community released package 15.0.0 on November 17, 2026, the first stable 15.x release. It depends on ansible-core 2.22.0 and ships a curated set of collections on PyPI, with a porting guide for collections that opted in. The project continues its roughly four-week release cadence.

Source

F5 Relevance

Teams that automate F5 BIG-IP, NGINX, and certificate workflows with Ansible should check collection compatibility with ansible-core 2.22 before upgrading shared automation estates that also touch load balancing and TLS.

Cisco
November 17, 2026

Cisco Multicloud Fabric enters controlled availability

Cisco put Multicloud Fabric into controlled availability on November 17, 2026. The managed network-as-a-service, introduced in June through Cisco Cloud Control, uses Cisco-operated virtual points of presence to carry site-to-cloud and cloud-to-cloud traffic across on-premises data centers, AWS, Azure, Google Cloud, and edge sites. Customers can start by onboarding Meraki MX devices and view connectivity in one Cisco Cloud Control operating model instead of per-cloud tools.

Source

F5 Relevance

Multicloud Fabric is a direct adjacency to F5 Distributed Cloud and BIG-IP multicloud networking. Alliance teams should map where customers will still need F5 for application delivery, WAF, and API security on top of Cisco's connectivity fabric.

Cisco
November 18, 2026

Cisco reports nearly 4,000 security fixes from six months of Project Glasswing

Cisco security chief Anthony Grieco said on November 18 that more than 50 engineers used frontier AI plus human review to scan over 6.7 billion lines of code, including third-party assets, over six months in Project Glasswing. About 1,500 engineers prioritized hardening over new features and delivered nearly 4,000 fixes in 2026 security hardening releases. Cisco is asking customers to move to those hardened releases and is shifting toward a predictable hardening cadence.

Source

F5 Relevance

The scale of AI-assisted code scanning is a signal for how network vendors will harden software supply chains. F5 can compare its own product-security cadence and position NGINX and BIG-IP inspection as the runtime control when partners ship faster, AI-assisted patches.

November 19, 2026

Epic pledges broader EHR access for external AI tools

FTMQ Health reported on November 19 that Epic Systems executives promised to make electronic health records more accessible to external AI tools, while defending the company against anticompetitive claims about data access. The report follows earlier coverage that Epic may have selectively limited access for rival developers. Epic remains the largest U.S. EHR vendor, so any change in how outside systems reach patient data is material for healthcare integrations.

Source

F5 Relevance

Wider Epic data access for external AI increases API and FHIR traffic that health systems will want to authenticate, rate-limit, and inspect. F5 can position BIG-IP and Distributed Cloud as the policy layer in front of Epic-connected AI agents.

HPE GreenLake
November 16, 2026

HPE-built Lux AI cluster debuts at No. 14 on the TOP500

HPE announced on November 16 that Lux, a joint HPE and AMD AI cluster built for Oak Ridge National Laboratory and the Department of Energy Genesis Mission, debuted at No. 14 on the TOP500 at 220.79 petaflops. The multi-tenant system uses direct liquid-cooled HPE ProLiant XD685 servers, AMD Instinct MI355X GPUs, EPYC CPUs, Pensando DPUs, and HPE Juniper 800G switches, with Data Center Director for lifecycle management. HPE is contributing $37 million in kind, and about half of Lux's annual node-hours are allocated to Genesis.

Source

F5 Relevance

Lux is a public reference for 800G AI fabrics with DPUs in the path. F5 can use it in conversations with HPE on securing and load-balancing inference traffic into national-lab and sovereign AI clusters that sit on GreenLake-class infrastructure.

Intel
November 18, 2026

Microsoft and Intel deepen Azure infrastructure collaboration

Intel and Microsoft announced on November 18 a multi-year expansion of their Azure infrastructure work. It covers Intel Foundry EMIB packaging for Azure first-party silicon, long-term Xeon supply including Diamond Rapids, Xeon with CXL for memory pooling, QuickAssist acceleration, and Trust Domain Extensions for confidential VMs that can move across hosts. Intel cites up to 2.3x performance and memory flexibility on Azure M-series v4 with CXL and Xeon 6, and up to 2.5x faster SQL backups on QAT-enabled VMs.

Source

F5 Relevance

CXL memory pooling, QAT crypto offload, and TDX confidential computing change how Azure customers place TLS termination and east-west security. F5 should track where BIG-IP and NGINX still add application-layer control that Intel silicon acceleration does not replace.

MinIO AIStor Memory reaches general availability at SC26

StorageReview reported on November 18 that MinIO made AIStor Memory generally available at SC26, moving it past the earlier technology preview. The release stores long-term agent memory, persistent workspaces, and secrets on infrastructure the customer controls, alongside AIStor Tables in one lakehouse. Datadog also certified AIStor for on-premises bring-your-own-cloud logs, so observability pipelines can query logs that stay in the customer's cluster.

Source

F5 Relevance

Nutanix Flow adds Microsoft Retina network observability

Nutanix said on November 17 that Flow, its networking and security platform for Kubernetes and virtual machines, now integrates with Retina, Microsoft's open-source eBPF observability project. The combination is meant to show throughput, drops, service dependencies, DNS, and TCP health for Kubernetes on Nutanix without a separate tool chain. It extends the Nutanix and Microsoft collaboration beyond Azure hosting into cloud-native network operations.

Source

F5 Relevance

eBPF visibility on Nutanix Flow is adjacent to F5's OpenTelemetry and NGINX Ingress telemetry. A joint story could export Flow and Retina signals into the same pipeline F5 uses for application and API health.

Coverage dated November 17 describes Nutanix Kubernetes Platform 2.19, which lets virtualized workloads and bare-metal Kubernetes clusters share the same hardware. NVIDIA announces Rubin HPC GPU for science and analytics agents

NVIDIA announced Rubin HPC on November 16, a Vera Rubin-platform GPU aimed at simulation and data processing for science, engineering, and analytics. The company cites more than 50,000 CUDA cores on one GPU, sparse-data acceleration, and seventh-generation NVLink for faster GPU-to-GPU links. Source
